## 🔐 Cryptage Vlansky (Outil RP)

- Interface de chiffrement/déchiffrement dédiée au **Roleplay**
- Utilisé pour les communications secrètes sur le serveur Minecraft
- Outil accessible via navigateur pour les joueurs

---

## Fonctionnement

L'outil permet de sécuriser des messages RP de deux manières :
- **Chiffrement** : Transforme un message clair en code complexe.
- **Déchiffrement** : Retrouve l'original à partir d'un message chiffré.

Idéal pour les factions, les complots ou les transmissions de coordonnées confidentielles en jeu.

---

## Confidentialité

✔ Traitement des messages côté client  
✔ Aucun stockage de données en base  
✔ Simple, rapide et thématique
